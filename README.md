# Personal Notebook App 🐍

A Python-based Desktop Application built using *Tkinter* for creating and managing daily notes efficiently.

### ✨ Key Features:
- *GUI Interface:* Easy to use desktop window.
- *Auto-save:* Notes are saved as text files with timestamps.
- *Python Powered:* Built with clean logic and file handling.
